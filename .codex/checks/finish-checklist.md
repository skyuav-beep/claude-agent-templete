# Finish Checklist

작업 종료 전 다음을 확인한다.

- `git status --short --branch`로 변경 범위를 확인했다.
- 관련 검증을 실행했다.
- 실행하지 못한 검증은 이유를 기록했다.
- 문서/운영 규칙 변경이면 `STATE.md`를 갱신했다.
- `DESIGN.md`를 바꿨다면 관련 design catalog와 `STATE.md` 변경 이력을 확인했다.
- 사용자가 요청했거나 저장소 규칙상 필요한 경우 변경 사항을 스테이징하고 커밋했다.
- 긴 답변이면 전체 구성을 먼저 안내하고, 한 단계 또는 핵심 항목을 가급적 30행 이내로 제공했는지 확인했다.
- 단계별 질문, 답변, 수정 사항, 결정 사항 중 마지막으로 확인된 내용을 다음 단계와 최종 통합에 반영했는지 확인했다.
- 최종 정리에서 최초 초안과 후속 결정이 충돌하면 후속 결정을 우선하고 최종 적용 기준을 명시했는지 확인했다.
- 최종 응답에는 변경 파일, 검증 결과, 남은 리스크를 간결히 남긴다.
