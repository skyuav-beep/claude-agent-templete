# Finish Checklist

작업 종료 전 다음을 확인한다.

- `git status --short --branch`로 변경 범위를 확인했다.
- 관련 검증을 실행했다.
- 실행하지 못한 검증은 이유를 기록했다.
- 문서/운영 규칙 변경이면 `STATE.md`를 갱신했다.
- `DESIGN.md`를 바꿨다면 관련 design catalog와 `STATE.md` 변경 이력을 확인했다.
- 사용자가 요청했거나 저장소 규칙상 필요한 경우 변경 사항을 스테이징하고 커밋했다.
- 최종 응답에는 변경 파일, 검증 결과, 남은 리스크를 간결히 남긴다.
