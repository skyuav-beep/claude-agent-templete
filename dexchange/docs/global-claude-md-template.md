# ~/.claude/CLAUDE.md (Global Template)

이 파일을 `~/.claude/CLAUDE.md`에 복사하면 모든 프로젝트에 공통으로 적용된다.
프로젝트별 규칙은 각 프로젝트의 `CLAUDE.md`에 정의한다.

## 사용법

```bash
cp docs/global-claude-md-template.md ~/.claude/CLAUDE.md
# 이후 개인 설정에 맞게 수정
```

---

아래는 템플릿 내용이다. `---` 아래를 `~/.claude/CLAUDE.md`에 복사한다.

---

## 응답 언어

- 모든 설명, 요약, 진행 보고는 한국어로 작성한다.
- 코드, 명령어, 경로, 식별자는 원문 그대로 유지한다.

## 스타일

- 이모지를 사용하지 않는다.
- 장황한 설명보다 결과와 다음 액션을 우선한다.
- 컨텍스트 낭비를 막기 위해 불필요한 수사는 사용하지 않는다.
