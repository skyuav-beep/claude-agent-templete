# 코드 리뷰 요청 구조화

코드 리뷰 요청을 대화형으로 구조화한다.

## 실행 방법

1. `templates/review-request.md` 파일을 읽는다.
2. 템플릿의 섹션(리뷰 대상, 중점 항목, 배경, 원하는 결과)을 순서대로 질문한다.
3. `$ARGUMENTS`가 PR 번호, 파일 경로, 또는 리뷰 대상 설명이면 해당 변경사항을 먼저 읽고 컨텍스트를 수집한다.
4. 모든 섹션이 채워지면 완성된 review-request 마크다운 블록을 출력한다.

## 인수 처리

- `$ARGUMENTS`가 PR 번호(예: `#123`)이면 해당 PR의 변경사항을 먼저 확인한다.
- `$ARGUMENTS`가 파일 경로이면 해당 파일의 최근 변경을 확인한다.
- `$ARGUMENTS`가 비어 있으면 "어떤 코드를 리뷰하고 싶은지" 질문으로 시작한다.

## 진행 규칙

- 중점 항목(성능, 보안, 가독성, 테스트 등)을 반드시 확인한다.
- 리뷰 범위가 넓으면 핵심 파일 우선순위를 정한다.

## 완료 후

구조화된 review-request 마크다운 블록을 출력하고, 바로 리뷰를 시작할지 사용자에게 확인한다.
