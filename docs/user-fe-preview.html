atomic 7종 (시안별 차이 비교)

활성 시안의 토큰으로 button-* / input / badge / chip / avatar / icon-button / icon이 즉시 재렌더링된다. 시안 dropdown을 변경하며 시안 간 시그너처 차이를 비교한다.

BUTTON — 5 variant × 4 size

시안 차이: wanted sm radius 6 / md radius 8 / lg radius 10 비-4 로컬값 · minimal-mono 4의 배수 정규화 · toss-like height 한 단계 큼 · material-3 radius-full + +0.10em letter-spacing · linear-like height 한 단계 작음 + radius-6

INPUT — default / focus / error / disabled
이메일 형식이 올바르지 않아요

시안 차이: 시안마다 height(linear-like 32 ~ toss-like 52, material-3 56) + radius(linear-like radius-6, minimal-mono radius-4, toss-like radius-12) 다름. focus glow는 모두 brand color alpha.

BADGE — active / pending / inactive / danger
진행중 대기 완료 취소 +12.4% v1.0.0

시안 차이: wanted/minimal-mono/toss-like/material-3 radius-full pill, linear-like radius-4 직사각(productivity 시그너처).

CHIP — interactive (selected/default)

시안 차이: wanted의 #해시 chip 시그너처 · material-3 input chip(radius-8) · linear-like radius-4 컴팩트.

AVATAR — 24 / 32 / 40 + fallback
홍 홍 김 이 박 최

시안 차이: linear-like 24 컴팩트 · wanted/minimal-mono/material-3 32 · toss-like 40 모바일 우선. 본 specimen의 그라디언트 채움은 wanted 시그너처(다른 시안에서는 단색 fallback 권장).

ICON-BUTTON — 28 / 36 / 40

시안 차이: linear-like는 radius-6(아닌 radius-full) 시그너처. 다른 시안은 모두 radius-full circle.

ICON — 16 / 20 / 24 / 32 (currentColor)

모든 시안 공통: currentColor 상속, monochrome, 2px stroke (linear-like는 1.5px), rounded line caps. 시안 무관.
