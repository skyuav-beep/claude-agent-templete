# Project Guide

이 문서는 현재 프로젝트에만 적용되는 개발 기준의 정본이다. 새 프로젝트에서는 intake 결과를 `docs/project-guide-template.md` 구조에 맞춰 이 파일에 반영한다.

## 적용 상태

- 상태: `[초기 템플릿 — 프로젝트별 작성 필요]`
- 작성 기준: `templates/startup-checklist.md`, `docs/project-guide-template.md`

## 프로젝트 기준

아래 항목을 프로젝트에 맞게 작성한다.

- 프로젝트 목표와 현재 범위
- 확정 사항과 미정 사항
- 기술 스택과 실행 명령
- 아키텍처와 디렉터리 규칙
- UI/UX와 반응형 기준
- 테스트와 검증 기준
- 배포·migration·Git 작업 경계
- 프로젝트 고유 제약과 금지 사항

## 우선순위

- 상위 런타임 규칙과 사용자의 최신 요청을 먼저 따른다.
- 그 범위 안에서 이 프로젝트 가이드와 프로젝트 로컬 문서를 템플릿 기본값보다 우선한다.
- 프로젝트 로컬 문서끼리 충돌하면 더 구체적인 작업 영역의 문서와 사용자가 마지막으로 확인한 결정을 우선하고, 적용 기준을 보고한다.
- 이 파일이 초기 템플릿 상태라면 확정되지 않은 항목을 임의로 채우지 않고 관련 템플릿 기본값을 사용한다.

## 변경 정책

- 요구사항이나 프로젝트 운영 방식이 바뀌면 구현 전에 관련 항목을 갱신한다.
- 프로젝트 가이드와 실제 작업 방식이 어긋나면 차이를 보고하고 문서 갱신을 제안한다.
- 결정 이력과 다음 작업은 `STATE.md`에 기록한다.
