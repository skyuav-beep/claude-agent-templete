## 메인 Brain과 두 봇의 연결·착수 후보

`메인 Brain의 프로젝트별 대화·작업 근거 → 프로젝트 정리 봇 → 출처가 있는 반복 실패 사례 → 스킬 업데이트 봇 → 검증된 개선 → 정리 봇의 관련 문서 갱신`

- 메인 Brain의 최초 구현 후보: MB-01~03(프로젝트·메시지 계약, 통합 대화창 목업, 기존 기록 읽기 어댑터). 실행 대상은 agent-deck이며 두 봇 완성과 독립적으로 착수한다.
- 메인 Brain 공통 계약(MB-01): [프로젝트 ID·메시지·승인 연결 계약](../04-design/2026-11-17__design__main-brain-conversation-contract.md) — agent-deck 구현의 정본.
- 정리 봇의 최초 구현 후보: 분류·근거 계약과 수동 호출 목차·TODO 후보 생성.
- 업데이트 봇의 최초 구현 후보: 대상 스킬 1종과 재현·평가 사례 선정.
- 두 봇은 독립적으로 착수할 수 있다. 정리 봇의 문서 ID·출처·기준 버전 계약을 먼저 정하면 이후 근거 전달 형식을 공유하기 쉽다.
- 세션별 실제 다음 작업과 우선순위는 [STATE](../../STATE.md)를 따른다. 자동 갱신·전용 역할·화면 구현은 각 계획의 후속 단계다.
