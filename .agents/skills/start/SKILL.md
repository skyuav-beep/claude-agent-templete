# Start Skill

> 경로 규칙: `templates/`·`agents/`·`docs/`는 프로젝트 루트를 먼저 찾고, 없으면 `rules/` 아래 같은 경로를 읽는다.

## 절차

1. `AGENTS.md`, `STATE.md`, `README.md`를 읽는다.
2. `templates/startup-checklist.md`의 섹션을 순서대로 진행한다.
3. 답변을 확정·미정·제외·제약으로 분류한다.
4. `docs/project-guide-template.md`를 기준으로 `docs/project-guide.md` 반영안을 만든다.
5. 실행 명령과 다음 작업을 제시하고, 변경 전 승인 절차를 적용한다.

## 입력 처리

- 시작할 섹션 번호가 명시되면 그 섹션부터, 없으면 1번부터 진행한다.

## 진행 규칙

- 한 번에 모든 질문을 쏟지 않는다. 섹션 단위로 끊고, 한 섹션의 질문은 모아서 제시한다.
- "모름"·"나중에"는 미정으로 분류하고 넘어간다. 건너뛰기 요청은 제외로 분류한다.
- 각 섹션이 끝나면 그 섹션 결과를 확정·미정·제외로 요약한 뒤 다음으로 넘어간다.

## 산출물

```
## 결과 요약
### 확정 사항
### 미정 사항
### 제외 사항
## 다음 액션
```

다음 액션에는 토픽 심화 수집(`intake`), 작업 시작(`request` 또는 개별 Skill), `docs/project-guide.md` 작성을 제시한다.

## 승인 절차 연결

수집 결과를 문서로 남기거나 파일을 바꾸는 단계부터 6단계 승인 절차를 적용한다. 상세 호환 절차는 `.codex/workflows/start.md`, 단계 봉투는 `.codex/README.md ## 단계 실행 계약`을 따른다.
