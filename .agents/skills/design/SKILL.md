# Design Skill

1. `DESIGN.md`를 1차 소스로 읽는다.
2. `docs/design-guidelines.md`와 화면 유형별 가이드를 확인한다.
3. 직접값보다 DESIGN token과 기존 컴포넌트를 우선 사용한다.
4. light/dark와 대상 viewport를 검증한다.
5. `DESIGN.md`나 catalog를 바꾸면 `STATE.md`에 변경 이력을 남긴다.

상세 절차는 `.codex/workflows/design.md`와 `.codex/agents/design-reviewer.md`를 따른다.
