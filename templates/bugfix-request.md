# Bugfix Request Template

## 문제 요약

- 어떤 버그인지 한 문장으로 적는다.

## 재현 방법

1. 어떤 환경에서
2. 어떤 동작을 했을 때
3. 어떤 문제가 발생하는지

## 기대 동작

- 원래 어떻게 동작해야 하는지 적는다.

## 영향 범위

- 관련 화면, API, 파일, 모듈을 적는다.

## 검증 기준

- 수정 후 어떤 테스트나 확인이 필요한지 적는다.

## 작성 예시

```
## 문제 요약
- 주문 상세 페이지에서 새로고침 시 상태 배지가 항상 "결제 대기"로 표시된다.

## 재현 방법
1. 크롬 최신 버전, 로그인 상태에서
2. `/orders/12345` 페이지를 열고 새로고침을 한다
3. 실제 상태가 "배송 중"인데 "결제 대기"로 보인다

## 기대 동작
- 새로고침 후에도 서버 응답 그대로 "배송 중"이 표시되어야 한다.

## 영향 범위
- `src/features/orders/pages/OrderDetail.tsx`
- `src/features/orders/hooks/useOrderStatus.ts`
- 관련 API: `GET /api/orders/:id`

## 검증 기준
- 동일 절차로 재현 시 정확한 상태가 표시된다.
- 상태별(결제 대기, 배송 중, 완료, 취소) 4개 케이스를 수동 확인한다.
- 회귀 방지용 단위 테스트 1건 추가.
```
