# Moa — design.md

> 직접 쓰고, AI와 함께 다듬는 하나의 작업대 — 종이 톤 뉴트럴 위에 모스 그린 브랜드 하나와 앰버 AI 시그널 하나만 쓰는 AI 워크스페이스 시안.

본 시안은 Claude Design System 「Moa」(https://claude.ai/artifact/Wnqi1DQEq96xCsFyV1qT9L)의 **스냅샷**이다. 원본 토큰 이름을 템플릿 별칭 계약(`designs/_alias-contract.md`)으로 옮긴 대응표는 `designs/_sync/moa.map.json`이고, `node scripts/design-sync.mjs adopt`가 이 파일을 다시 만든다. 이 파일을 직접 고치지 않는다 — 디자인은 Claude 쪽에서, 대응은 대응표에서 고친다.

| TaskBoard | Tasks 모듈의 보드(칸반) 보기입니다. |
| ThemeCompare | Paper · White · Dark 세 테마를 같은 셸 축약도로 나란히 비교합니다. |
| WhiteModeBusiness | White 테마의 ERP 대시보드로, 기업판 기본 테마 제안의 예시입니다. |
| WhiteModeShell | White 테마로 고정해 보여 주는 전체 셸입니다. |

## Known Gaps

- 원본 테마는 light(Paper)·white·dark 3종이다. 템플릿은 light/dark 2종만 받으므로 white 값은 원본 문서 06 'White 모드'에만 남는다.
- 원본 간격 이름은 단계 번호(space-1=4px … space-8=32px)라 템플릿 이름(space-4=4px)으로 값 기준 재매핑했다.
- 라운드 6·10·14는 4의 배수가 아니라 시안 전용 토큰(radius-6/10/14)으로 원래 값을 유지한다(계약 9b).
- `bg-inverse` ← `ink`: 합성 — 원본에 반전 면이 없어 본문 잉크를 재사용
- `bg-success-subtle` ← `brand-soft`: 합성 — 원본은 승인·완료를 brand 계열로 표시
- `bg-warning-subtle` ← `surface-300`: 합성 — 원본은 상태색을 배지·텍스트로만 써서 상태 바탕이 없음(중립 채움)
- `bg-danger-subtle` ← `surface-300`: 합성 — 원본은 상태색을 배지·텍스트로만 써서 상태 바탕이 없음(중립 채움)
- `fg-disabled` ← `ink-faint`: 합성 — 원본 ink-faint(플레이스홀더·비활성 아이콘 전용) 재사용
- `fg-success` ← `brand`: 합성 — 원본에 성공색이 없어 brand 재사용

## 원본 문서

#### Moa

**직접 쓰고, AI와 함께 다듬는 하나의 작업대.**
Moa(모아)는 포스트잇·MD·블록 문서·연락처·할 일·일정·프로젝트·아이디어를 한 화면에 모으고, 오른쪽의 AI가 지금 열린 탭을 보면서 같이 일하는 웹앱 워크스페이스입니다. 개인 생산성 도구로 시작해 Studio(이미지·설계·3D·영상)와 비즈니스 팩(ERP·업무관리)으로 확장됩니다.

> 이 문서는 UI/UX 컨셉 제안서이자 디자인 시스템의 기준입니다. 레이아웃 · 정보 구조 · AI 인터랙션 · 창의 도구 · 에디션/로드맵은 뒤의 섹션에서 이어집니다. 플랫폼 이름 “Moa”와 모든 수치는 제안용 가칭·초안입니다.

##### 1. 핵심 컨셉

| 원칙 | 의미 | 화면에서 보이는 방식 |
|---|---|---|
| **사람이 먼저 쓴다** | 기본은 직접 작성. AI는 부르면 오고, 끝나면 비켜선다. | 작업 캔버스가 화면 중심(가장 넓은 면). AI 패널은 ⌘J로 접힘. |
| **AI 결과는 제안으로 도착한다** | AI가 문서를 몰래 고치지 않는다. 모든 변경은 미리보기 → 적용. | `ai-soft` 바탕 + 점선 `ai` 테두리의 제안 카드, diff 표시(삭제 취소선 / 추가 하이라이트). |
| **모든 것은 연결된 오브젝트** | 포스트잇·문서·태스크·연락처는 같은 오브젝트 모델. @멘션, [[링크]], 변환이 자유롭다. | 멘션 칩에 모듈 색 아이콘, 사이드 “연결된 항목” 목록. |
| **탭은 작업, 세션은 맥락** | 탭시트 = 지금 하는 일, 사이드바의 AI 세션 = 그 일을 하던 대화. 세션을 열면 탭이 같이 복원된다. | 세션 항목에 모듈·시간 메타, 활성 세션은 `ai-soft`. |
| **하나의 셸, 여러 편집기** | 새 도구(3D, 영상, ERP)가 와도 상단바·사이드바·탭·AI 패널은 그대로. 바뀌는 건 캔버스뿐. | Studio·ERP도 같은 5영역 레이아웃을 공유. |

##### 2. 시각 기반 (Visual foundations)

**톤:** 차분한 종이 톤 뉴트럴 위에 브랜드색 하나(모스 그린 `brand`)와 AI 시그널 하나(앰버 `ai`). 화면 대부분은 무채색이고, 색은 “어디가 활성인지”와 “무엇이 AI에서 왔는지”만 말한다.

###### 색 사용 규칙
- **면 계층은 4단계:** `surface-0`(앱 바탕) → `surface-100`(패널·캔버스) → `surface-200`(카드·입력) → `surface-300`(hover·선택·코드). 경계는 그림자 대신 `line` hairline.
- **`brand`는 행동과 활성 상태에만:** 주요 버튼 1개/화면, 활성 탭 인디케이터, 체크, 포커스 링(`focus`). 선택 상태 바탕은 `brand-soft` + 텍스트 `brand-strong`.
- **`ai`는 AI 출처 표시에만:** AI 버튼, 제안 카드, 생성 중 표시, AI 세션 아이콘. 사람이 만든 콘텐츠에는 절대 쓰지 않는다 → 사용자가 색만 보고 “AI가 만든 것”을 구분할 수 있어야 함.
- **모듈 색(`mod-*`)은 식별용:** 아이콘·점·탭 인디케이터·카드 상단 4px 띠에만. 넓은 면 채우기 금지(예외: 포스트잇 `mod-note`). 모듈 색은 항상 아이콘+라벨과 함께 쓰므로 색만으로 구분하지 않는다.
- **상태색(`danger`, `warning`)은 작게:** 배지·텍스트·아이콘. 큰 면에 깔지 않는다.
- 모든 텍스트 조합은 세 테마에서 4.5:1 이상. 예외 `ink-faint`(light 4.0:1, white 4.4:1)는 플레이스홀더·비활성 아이콘 전용.

###### 테마 3종
| 테마 | 성격 | 기본 사용처 |
|---|---|---|
| **Light · Paper** (기본) | 따뜻한 종이 톤, 3단 면 위계 | 개인판, 장시간 글쓰기 |
| **White** | 순백 면 + 선 구분, 진한 컨트롤 테두리, 쿨 뉴트럴 | 기업판 기본, 업무·ERP·표, 화면 공유·인쇄 |
| **Dark** | 저조도 | Studio 편집, 야간 |

토큰 이름은 세 테마가 같고 값만 다릅니다. White 전용 화면 규칙은 ‘White 모드’ 섹션을 따릅니다.

###### 타이포그래피
- 한글 우선 산세리프 **Noto Sans KR**(Google Fonts; Pretendard 사용 가능 시 대체), 코드·MD 원문은 **JetBrains Mono**.
- 인터페이스 기본은 `body`(14/22)와 `body-sm`(13/20). 문서 제목만 `page-title`(26/34, 700). 한 화면에 굵기는 400·500·600·700 중 최대 3개.
- 섹션 라벨은 `caption`(11/14, 자간 +0.02em)과 `ink-muted`, 대문자 영문 라벨은 STUDIO처럼 짧은 그룹명에만.

###### 간격 · 모서리 · 깊이
- 4px 그리드: `space-1`(4) `space-2`(8) `space-3`(12) `space-4`(16) `space-6`(24) `space-8`(32).
- 모서리: 작은 컨트롤 `radius-sm`(6), 카드·입력 `radius-md`(10), 컴포저·모달 `radius-lg`(14), 배지·토글 `radius-pill`.
- 깊이: 기본은 평면 + `line`. `shadow-1`은 포스트잇·hover, `shadow-pop`은 팝오버·커맨드 팔레트·드래그 중에만.
- 레이아웃 치수: `topbar-h` 48 · `tabbar-h` 40 · `sidebar-w` 248(접힘 `sidebar-rail-w` 56) · `ai-panel-w` 380 · `statusbar-h` 28.

###### 밀도
- **Comfortable(기본):** 내비 30px, 리스트 행 36px, 패널 여백 `space-4`.
- **Compact(ERP·표 중심 화면):** 행 28px, 패널 여백 `space-3`, `body-sm` 기본. 설정에서 전환하며 토큰 값은 같고 컴포넌트 높이만 바뀐다.

###### 모션
- 120ms(hover·토글) / 180ms(패널 열고 닫기, 탭 이동) / 240ms(모달). ease-out. 패널은 밀어내기(push), 오버레이 아님.
- AI 생성 중: 앰버 점 3개가 순서대로 깜빡이는 표시만. 스켈레톤 반짝임·무지개 그라디언트 금지.
- `prefers-reduced-motion`에서는 모두 즉시 전환.

##### 3. 아이콘

- 24 그리드, 선 굵기 1.6, 둥근 끝 — Lucide 계열 아웃라인 스타일. 기본 16px(내비·툴바), 14px(칩·메타), 18–20px(Studio 레일).
- 아이콘 색은 기본 `ink-muted`, 활성 시 `brand-strong`, 모듈 아이콘은 해당 `mod-*`, AI는 `ai`의 스파크(✦) 하나로 통일.
- 모듈별 고정 아이콘: 포스트잇=접힌 메모, MD=M↓ 상자, Docs=문서, 연락처=사람, Tasks=체크 상자, Plan=캘린더, Projects=폴더, Ideas=전구, Diagram=연결된 사각형. 이미지·설계(펜)·3D(큐브)·영상(카메라).
- 아이콘 세트 파일은 아직 업로드되지 않았습니다. 컴포넌트 미리보기의 인라인 SVG가 기준 형태입니다.

##### 4. UI 문구 (Content fundamentals)

- **해요체, 짧게.** “문서를 저장했어요.” / 버튼은 동사형 명사구: “모두 추가”, “적용”, “버리기”.
- **AI는 1인칭으로 무엇을 했는지 먼저 말한다:** “두 항목을 실행 단위로 나눴어요. 담당자와 마감은 문서 속성에서 가져왔습니다.” 과장·감탄사·이모지 없음.
- **AI 출처를 숨기지 않는다:** AI가 만든 항목에는 `AI` 배지가 남고, 사람이 수정하면 배지가 사라진다.
- 날짜는 `11/9`, `11월 9일`, 상대 시간 “3분 전 · 어제”. 금액은 `₩ 1,280,000` 또는 `₩ 1.28억`.
- 빈 상태는 다음 행동 하나를 제안: “/ 를 입력해 블록 추가, 스페이스로 AI에게 요청”.

##### ① 상단바 (`topbar-h` 48)
- **왼쪽:** 로고, 워크스페이스 전환(개인 / 팀 / 회사). 전환하면 사이드바·탭 전체가 그 공간으로 바뀐다.
- **메뉴:** 파일 · 편집 · 보기 · 삽입 · AI · 도구 · 도움말. 데스크톱 앱 같은 익숙함을 주되, 모든 메뉴 항목은 ⌘K 커맨드 팔레트에서도 검색 가능.
- **가운데:** 통합 검색 + 명령(⌘K). 오브젝트 검색, 명령 실행, “AI에게 묻기”가 한 입력창.
- **오른쪽:** `AI 열기`(⌘J), 알림, 프로필.

##### ② 사이드바 (`sidebar-w` 248, 접힘 56)
1. **새로 만들기** — 유일한 `brand` 주요 버튼. 누르면 모듈 선택 + “AI로 시작” 옵션.
2. **홈 · 받은함** — 홈은 오늘의 할 일·최근 문서·AI 브리핑, 받은함은 멘션·결재·공유 알림.
3. **라이브러리** — 포스트잇, MD 문서, Docs, 연락처, Tasks, Plan, Projects, Ideas, Diagram. 각 항목은 모듈 아이콘 색 + 개수. 사용자 정의 컬렉션(필터 저장)을 아래에 추가.
4. **STUDIO** — 이미지, 설계·CAD, 3D, 영상. 설치 전엔 `확장` 배지, 설치 후 일반 항목.
5. **비즈니스** — 기업판에서만 노출(고객·거래처, 재고·구매, 회계, 전자결재, 인사·근태).
6. **AI 세션** — 진행하던 대화 기록. 최근순, 고정(📌), 검색. 항목 = 세션 제목 + 연결 모듈 · 시간. 세션을 열면 그 세션이 참조하던 탭이 탭시트에 함께 열린다.
- 섹션은 접을 수 있고 순서는 드래그로 바꾼다. 폭 200–320px 드래그, 1280px 미만에서는 자동으로 아이콘 레일.

##### ③ 탭시트 (`tabbar-h` 40 + 컨텍스트 툴바 40)
- **탭 = 열린 오브젝트.** 아이콘은 모듈 색, 활성 탭은 위쪽 2px 모듈색 인디케이터와 `surface-100` 바탕으로 캔버스와 이어진다.
- **고정 탭:** 아이콘만 남는 좁은 탭(예: 이번 주 Tasks).
- **분할:** 탭을 오른쪽으로 끌거나 ⫴ 버튼 → 좌우 2분할(문서 + 다이어그램 동시 편집). 최대 2분할.
- **탭 그룹:** 프로젝트 단위로 묶고 접기. 그룹명은 프로젝트명.
- **AI 표시:** AI가 백그라운드로 작업 중이거나 미적용 제안이 있는 탭에는 앰버 점.
- **오버플로:** 탭이 넘치면 폭이 줄어 제목이 말줄임 → 최소 폭 이후 `⋯` 메뉴로.
- **컨텍스트 툴바:** 탭 아래 한 줄. 왼쪽 경로(브레드크럼), 오른쪽은 모듈별 도구 + `AI 다듬기` + 버전 기록 + 공유.

##### ④ 작업 캔버스
- 탭의 모듈에 맞는 편집기를 렌더링한다. 문서형은 가운데 정렬 720px, 캔버스형(Ideas·Diagram·Studio)은 전체 폭.
- 직접 작성이 기본. AI 제안은 캔버스 안에서 해당 위치에 인라인 카드로 도착하고 사용자가 적용/수정/버리기.

##### ⑤ AI 패널 (`ai-panel-w` 380, 320–560)
- 헤더: 세션 제목(편집 가능) + 모드 토글 `대화 · 제안 · 실행` + 메뉴(세션 저장, 새 세션, 내보내기).

- 대화 영역 → 액션 카드 → 컴포저 순. 상세 규칙은 “AI 인터랙션” 섹션.

#### AI 인터랙션

##### 세 가지 접점
| 접점 | 언제 | 형태 |
|---|---|---|
| **AI 패널(우측)** | 긴 대화, 여러 탭에 걸친 일, 리서치 | 대화 + 액션 카드 |
| **인라인 AI** | 지금 쓰는 자리에서 바로 | 빈 줄에서 `Space`, 블록 선택 후 `AI 다듬기`, `/` 메뉴의 AI 그룹 |
| **커맨드(⌘K)** | 한 줄 요청 | “이번 주 할 일 요약”, “박지훈 미팅 브리핑” → 결과를 패널로 |

##### 패널의 세 모드
| 모드 | AI가 하는 일 | 사용자 확인 |
|---|---|---|
| **대화** | 답하고 설명만 한다. 오브젝트를 바꾸지 않는다. | 없음 |
| **제안**(기본) | 변경안을 액션 카드/인라인 diff로 만든다. | 적용 · 수정해서 적용 · 버리기 |
| **실행** | 승인된 범위 안에서 여러 단계를 직접 수행(태스크 생성 → 일정 배치 → 메일 초안). | 시작 전 계획 승인, 끝나면 변경 요약 + 한 번에 되돌리기 |

##### 액션 카드
AI가 무언가를 만들거나 바꿀 때 항상 이 카드로 보여 줍니다.
- 헤더: 대상 모듈 아이콘(모듈 색) + “Tasks 4개 만들기” + `미리보기` 배지.
- 본문: 생성/변경될 항목 목록 — 개별 체크 해제 가능.
- 푸터: `모두 추가`(brand) · `골라서 추가` · 연쇄 동작(“Plan에도 배치”).
- 적용 후: 카드는 접히고 “4개 추가됨 · 되돌리기” 한 줄로 남는다.

##### 인라인 제안 카드
- `ai-soft` 바탕 + 1px 점선 `ai` 테두리. 사람 콘텐츠와 시각적으로 절대 섞이지 않게.
- 수정 제안은 diff: 삭제는 `danger` 취소선, 추가는 `brand-soft` 하이라이트.
- `⌘⏎` 적용, `Esc` 버리기, `Tab`으로 다음 제안.

##### 컨텍스트 규칙
- 기본 컨텍스트 = 현재 활성 탭 + 선택 영역. 칩으로 보여 주고, X로 뺄 수 있다.
- `@`로 다른 문서·연락처·프로젝트를 추가. 드래그로 사이드바 항목을 패널에 끌어 넣기.
- AI가 무엇을 읽었는지 메시지마다 “참고: Q4 런칭 플랜, 연락처 2” 로 접힌 출처 표시.

##### AI 세션 저장
- 새 대화는 자동으로 세션이 된다. 제목은 AI가 첫 요청으로 제안, 사용자가 수정.
- 세션은 대화 + 컨텍스트로 쓴 탭 목록 + 세션에서 만든 오브젝트 목록을 함께 저장.
- 사이드바에서 세션을 열면 → 패널에 대화 복원 + 연결 탭 재오픈(“3개 탭 열기?” 확인).
- 세션을 오브젝트처럼 프로젝트에 연결하거나, Docs로 “대화 요약 문서” 내보내기.

##### 신뢰와 안전
- AI가 만든 오브젝트는 `AI` 배지, 사람이 편집하면 사라짐. 출처 필터로 “AI가 만든 것만 보기”.
- 되돌리기는 AI 적용 단위로 묶인다(한 번의 ⌘Z = 한 번의 적용).
- 기업판: 결재·회계 데이터는 AI가 “제안” 모드로만 접근(실행 모드 불가), 관리자 정책으로 모듈별 AI 접근 제한.
- 사용량은 상태바의 AI 크레딧으로 항상 보이게.

#### 창의 도구 — Ideas · Diagram · Studio

##### Ideas: 발산 → 수렴 캔버스
- 무한 캔버스, 16px 점 격자(`line-strong`). 왼쪽 세로 툴(선택·이동·포스트잇·도형·텍스트·화살표), 아래 떠 있는 AI 바.
- **발산:** 노드를 선택하고 `발산: 아이디어 더` → AI 아이디어가 점선 `ai` 테두리의 “유령 노드”로 붙는다. 클릭하면 실제 노드로 확정(실선·모듈 색), 무시하면 사라진다.
- **수렴:** `묶고 점수` → 비슷한 노드를 클러스터로 묶고, 사용자가 정한 기준(영향·노력·비용)으로 점수표 생성.
- **출구:** 선택한 클러스터를 `다이어그램으로` / `태스크로` / `Docs 기획서로` 변환.
- 기법 템플릿: 마인드맵, SCAMPER, 6색 모자, 린 캔버스, 고객 여정 지도, 2×2 매트릭스.

##### Diagram: 텍스트가 곧 그림
- 왼쪽 텍스트(자연어 또는 Mermaid 유사 문법) ↔ 오른쪽 캔버스 양방향 동기화.

- AI: “이 문서의 프로세스를 플로우로”, “ERP 테이블 구조로 ERD”, 기존 그림의 빠진 분기 지적.
- 노드는 다른 오브젝트에 링크 가능(조직도 노드 = 연락처, 플로우 노드 = 태스크).

#### White 모드 — 순백 기준 디자인 제안

기본 Light(Paper)는 따뜻한 종이 톤 3단 면 위계를 씁니다. **White 모드**는 같은 레이아웃·컴포넌트·토큰 이름을 그대로 두고 값만 바꾼 세 번째 테마(`white`)입니다. 면은 모두 순백이고, 영역은 색 차이가 아니라 **선과 상태 표시**로 나눕니다.

##### 언제 쓰나
| 상황 | 추천 테마 |
|---|---|
| 장시간 글쓰기, 개인 노트·문서 | Light · Paper (기본) |
| 업무관리·ERP·표·대시보드, 밝은 사무실, 화면 공유·발표, 인쇄 미리보기 | **White** |
| 저조도 환경, Studio(이미지·영상) 편집, 야간 | Dark |
- 기업판은 워크스페이스 기본 테마를 **White**로 제안합니다. 사내 문서·결재 양식이 흰 종이 기준이고, 화면 캡처가 그대로 보고서에 들어가기 때문입니다.
- 사용자는 설정 › 화면에서 `시스템 따라가기 / Paper / White / Dark` 중 선택. 시스템 라이트 → 개인판 Paper, 기업판 White로 연결.

##### Paper와 무엇이 다른가
| 항목 | Light · Paper | White |
|---|---|---|
| 바탕 `surface-0/100/200` | #f6f4ef / #fbfaf7 / #fff — 3단 톤 | 모두 #ffffff |
| 채움 `surface-300` | 웜 그레이 #efece5 | 쿨 그레이 #f2f4f6 |
| 경계 `line` | #e3dfd6 | #e6e8eb (뉴트럴) |
| 컨트롤 테두리 `line-strong` | #cdc7bb (장식 수준) | #8c939b — 흰 바탕 3:1, 입력창·버튼 윤곽이 분명 |
| 텍스트 `ink` / `ink-muted` | #1f211d / #5e6058 | #111418 / #5b626b (6.2:1) |
| 브랜드 `brand` | #2f6b4f | #23704d — 흰 바탕에서 조금 더 맑은 모스 |
| AI `ai` / `ai-soft` | #9a4f08 / #fbeedd | #a3540a / #fff3e3 |
| 포스트잇 `mod-note` | #f5d76e | #fbe38c — 흰 바탕에서 덜 탁하게 |
| 그림자 | 아주 옅게 | 한 단계 진하게(`shadow-pop` 0 12 32 / 14%) — 면 차이가 없으니 띄움은 그림자가 맡음 |

##### 화면 규칙 (White 전용)
1. **구획은 1px `line`으로만.** 상단바·사이드바·탭바·AI 패널 사이 모두 선. 면을 회색으로 칠해 구분하지 않는다(사이드바도 흰색).
2. **선택 상태는 회색 채움 + 브랜드 아이콘.** 사이드바 활성 항목은 `surface-300` 바탕, 텍스트 `ink`, 아이콘·개수 `brand`. 넓은 `brand-soft` 면은 블록 선택에만.
3. **활성 탭은 선 + 위쪽 2px 모듈색.** 탭바와 캔버스가 같은 흰색이므로 활성 탭 테두리(`line`)가 연결을 보여 준다.
4. **떠 있는 것만 그림자.** 컴포저, 팝오버, 커맨드 팔레트, 드래그 중 카드에 `shadow-1`/`shadow-pop`. 일반 카드는 선만.
5. **AI는 여전히 앰버 하나.** 흰 바탕에서 `ai-soft`가 유일한 따뜻한 면이 되어 “AI가 만든 것”이 Paper보다 더 또렷하게 보인다.
6. **검색창·입력창은 흰 바탕 + `line` 테두리.** 회색 채움 입력창은 쓰지 않는다.
7. **표·ERP:** 헤더 행만 `surface-300`, 행 구분 `line`, Compact 밀도(행 28–32px). 숫자 우측 정렬·고정폭 숫자.
8. **캔버스(Ideas·Diagram):** 흰 바탕에 16px 점 격자 `line`(진한 `line-strong` 대신) — 흰 화면에서 점이 시끄럽지 않게.

##### 접근성
- 텍스트 조합은 모두 4.5:1 이상(`ink-faint` 4.4:1 — 플레이스홀더 전용).
- 입력창·버튼 테두리 `line-strong` 3.1:1로 컨트롤 윤곽 기준 충족(Paper 테마보다 개선).
- 흰 화면 눈부심 완화: 문서 본문 폭 720px 유지, 본문 `ink`를 순흑 대신 #111418.
