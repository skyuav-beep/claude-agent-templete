# 기능 요청 구조화

신규 기능 요청을 대화형으로 구조화한다.

## 실행 방법

1. `templates/feature-request.md` 파일을 읽는다.
2. 템플릿의 섹션(목표, 배경, 원하는 산출물, 제약사항, 검증 기준)을 순서대로 질문한다.
3. 사용자 메시지에 기능 설명이 포함되어 있으면 가능한 항목을 먼저 채우고 부족한 부분만 추가 질문한다.
4. 모든 섹션이 채워지면 완성된 feature-request 마크다운 블록을 출력한다.

## 입력 처리

- 사용자 메시지에 기능 설명이 있으면 목표/배경을 미리 채운다.
- 설명이 부족하면 "어떤 기능을 추가하고 싶은지" 질문으로 시작한다.

## 진행 규칙

- 섹션별로 끊어서 자연스럽게 질문한다.
- 사용자가 간단히 답하면 그대로 반영하고 다음으로 넘어간다.
- 검증 기준은 반드시 수집한다.

## 완료 후

구조화된 feature-request 마크다운 블록을 출력하고, 바로 구현을 시작할지 사용자에게 확인한다.
