# 새 프로젝트 시작 QnA

새 프로젝트의 초기 설정을 위한 대화형 QnA를 진행한다.

> 경로 규칙: 아래 `templates/`·`agents/`·`docs/` 경로는 프로젝트 루트 기준이다. 프로젝트에 해당 파일이 없으면 `rules/` 아래 같은 경로를 읽는다(공통 템플릿을 `rules/` symlink로 연결한 프로젝트).

## 실행 방법

1. `templates/startup-checklist.md` 파일을 읽는다.
2. 파일에 정의된 섹션을 순서대로 사용자에게 질문한다.
3. 각 섹션의 질문을 한 번에 모아서 제시한다.
4. 답변을 받으면 해당 섹션의 결과를 **확정 / 미정 / 제외**로 분류해서 요약한다.
5. 모든 섹션이 완료되면 전체 결과를 하나의 요약으로 정리한다.
6. `docs/project-guide-template.md` 구조를 참고해 `docs/project-guide.md`를 프로젝트 가이드 정본으로 작성한다.

## 입력 처리

- 사용자 메시지에 시작할 섹션 번호가 명시되면 해당 섹션부터 시작한다.
- 별도 지정이 없으면 섹션 1부터 시작한다.

## 진행 규칙

- 한 번에 모든 질문을 쏟지 않는다. 섹션 단위로 끊어서 진행한다.
- 사용자가 "모름" 또는 "나중에"라고 하면 해당 항목을 **미정**으로 분류하고 넘어간다.
- 사용자가 명시적으로 건너뛰기를 요청하면 해당 섹션을 **제외**로 분류한다.

## 완료 후 출력 형식

```
## 결과 요약

### 확정 사항
- ...

### 미정 사항
- ...

### 제외 사항
- ...

## 다음 액션
- 특정 토픽을 더 깊이 수집하고 싶다면 토픽명을 말한다 -> `intake` skill이 활성화된다.
- 작업을 시작하려면 작업 내용을 설명한다 -> `request` skill 또는 `feature` / `bugfix` / `refactor` / `review` / `business-logic` skill이 활성화된다.
- `docs/project-guide-template.md` 구조를 참고한 `docs/project-guide.md` 작성을 제안한다.
```

## 승인 절차 연결

- 수집·점검 결과를 문서로 남기거나 코드를 바꾸는 단계부터 `docs/approval-workflow.md`의 6단계 승인 절차를 적용한다. 한 턴에는 한 단계만 진행한다.
- 시작·종료 게이트는 `.claude/CLAUDE.md`, 종료 확인 목록은 `docs/finish-checklist.md`를 적용한다.
