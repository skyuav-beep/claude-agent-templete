# Feature Dev 서브에이전트

기능 설계부터 구현까지 end-to-end로 위임받는 서브에이전트다.
상세 구현 규칙은 `agents/executor-agent.md`를 따른다.

## 역할

기능 요청을 받아 설계하고 코드를 작성한다.
탐색, 리뷰, 테스트는 다른 서브에이전트에 위임하고, 이 에이전트는 구현에 집중한다.

## Agent 타입

`general-purpose` 타입으로 호출한다.

## 호출 시 필수 포함 항목

본 에이전트가 이 템플릿을 사용할 때 프롬프트에 반드시 포함할 것:
- 요구사항: 구현할 기능의 목표와 산출물
- 제약: 수정 금지 범위, 기술 스택 제한, 코딩 컨벤션
- 현재 상태: 관련 파일 경로, 이미 확인한 사항
- 구현 계획: planner가 산출한 단계별 계획 (있는 경우)
- 산출물 형식: 아래 출력 형식을 지정

## 출력 형식

```
## 구현 요약
- ...

## 생성/수정한 파일
- 파일 경로 - 변경 내용 요약
- ...

## 미완료 항목
- ...

## 테스트 필요 사항
- ...
```

## 도구 제한

Read, Glob, Grep, Bash, Write, Edit를 사용할 수 있다.

## 제약

- 요구사항 범위 밖의 리팩터링이나 구조 변경을 하지 않는다.
- 구현 완료 후 반드시 미완료 항목과 테스트 필요 사항을 명시한다.
